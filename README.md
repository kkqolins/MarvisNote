# Marvis 星露谷笔记本

> 一本会呼吸的像素风笔记本：把星露谷的松弛感，装进你的每一页笔记。

**一句话定位**：绿色免安装、离线即用的桌面笔记工具，以星露谷物语皮面笔记本为设计蓝本，让写笔记这件事变得轻松、好看、像在游戏里一样顺手。

## 核心亮点

### 1. 星露谷风格，一眼入戏
皮面笔记本外观 + 白纸 / 牛皮纸 / 古纸 / 羊皮纸 4 种纸张样式（带横线纹理），配合星露谷像素字体（FusionPixel）与经典小黄鸡图标，打开即进入游戏般的书写氛围。

### 2. 所见即所得，纸张也随行
编辑与导出保持一致：Word、PDF 导出时会完整保留当前纸张底色、横线与文字样式，写出来什么样，导出来就是什么样。

### 3. 多笔记本多笔记页，目录自由折叠
支持多本笔记本，每本内可建多页笔记；侧边目录可折叠收纳，自动保存、历史保留，笔记再多也不怕乱。

### 4. 富文本编辑，够用且顺手
加粗 / 斜体 / 下划线 / 删除线、对齐、列表、插入图片、Ctrl+V 直接粘贴截图，再配上 emoji 贴纸面板与 19 款目录图标，表达方式足够丰富。

### 5. 绿色免安装，双击即用
无需安装、不写注册表，离线可用；单文件夹即拷即走，U 盘、网盘、同事电脑都能直接跑。

## 功能清单

### 外观与氛围
- **皮面笔记本 UI**：整体界面模拟真实皮面笔记本质感
- **4 种纸张样式**：白纸 / 牛皮纸 / 古纸 / 羊皮纸，均带横线纹理，可随时切换
- **星露谷像素字体**：内置 FusionPixel 像素字体，还原游戏字感
- **小黄鸡图标**：应用与界面点缀均使用星露谷经典小黄鸡形象
- **自定义品牌字样**：左上角品牌字样可自由修改

### 笔记管理
- **多笔记本**：可创建多本笔记本，按主题分门别类
- **每本多笔记页**：单本内可建立多页笔记，独立记录
- **目录可折叠**：侧边目录一键折叠，聚焦当前内容
- **自动保存**：内容实时落盘，无需手动保存
- **历史保留**：笔记历史完整保留，误操作可回溯
- **19 款目录图标**：为每页笔记选择喜欢的图标标识

### 富文本编辑
- 加粗 / 斜体 / 下划线 / 删除线
- 左对齐 / 居中 / 右对齐
- 有序列表 / 无序列表
- 插入本地图片，或直接 Ctrl+V 粘贴截图
- **emoji 贴纸面板**：内置贴纸可选，也支持增删自定义贴纸
- **右键快捷菜单**：常用操作就近直达

### 文字样式
- **字号灵活**：12~100 档位快捷选择，另支持自定义数值（8-200px）
- **字体切换**：多款字体任选
- **文字颜色与底纹**：突出重点、标记批注更方便
- **笔记页标题**：每页可自定义标题

### 导出与备份
- **导出 Word（.doc）**：文字内容完整保留
- **导出 PDF**：所见即所得，含纸张底色与横线纹理
- **导出 .mbook 备份**：完整备份笔记数据
- **导入 .mbook 恢复**：换机、迁移一键恢复

## 使用说明

1. 解压绿色版压缩包，双击 `Marvis星露谷笔记本.exe` 即可启动，无需安装。
2. 新建笔记本 → 新建笔记页 → 选择喜欢的纸张样式，直接开写。
3. 需要分享或备份时，使用右上角导出：Word / PDF / .mbook。
4. 换电脑时，把整个文件夹拷走，或导入 .mbook 备份即可无缝迁移。
